# Suraya (ثریا)

بلاکچین نسل بعدی با Proof of Intelligence، توکن ARZA و جهان دیجیتال هوشمند.

## ساختار

Suraya-ai/
├── core/blockchain.js
├── contracts/Suraya.sol
├── world/engine.js
├── frontend/world.vue
├── docs/WHITEPAPER.md
├── docker-compose.yml
├── package.json
└── README.md

## اجرا

npm start
npm test

## لایه‌ها

1. Core – پروتکل + PoI
2. Contracts – ARZA + جهان + موجودیت + مأموریت + DAO + خزانه + NFT
3. World – موجودیت‌ها + بازی + مدیریت مراکز
4. Frontend – رابط جهان
5. Docs – مستندات

## ساختار مدیریتی

- مرکزیت اصلی متعلق به مالک (ادمین)
- زمین مرکزی هر شهر
- ابلاغ قوانین از مراکز به کل جهان
- سند زمین بر اساس فعالیت بازیکن
- اختیار کامل مالک
- کارمندان مراکز فعلاً تعریف نشده
