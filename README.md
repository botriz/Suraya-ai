# 🌟 ثریا - Suraya Blockchain

## بلاکچین و جهان دیجیتال هوشمند

### 🚀 شروع سریع

```bash
npm install
cp .env.example .env
npm run dev
```

### 📁 ساختار پروژه

```
Suraya-ai/
├── server.js              # سرور اصلی
├── blockchain/            # بلاکچین و قراردادها
│   ├── contracts/         # قراردادهای Solidity
│   ├── sdk/              # SDK اتصال
│   └── scripts/          # اسکریپت‌های مدیریتی
├── world-engine/          # موتور جهان دیجیتال
│   ├── core/             # هسته‌های اصلی
│   ├── entities/         # 15 موجودیت هوشمند
│   └── cities/           # شهرهای جهانی
├── api/                  # API بک‌اند
│   ├── routes/           # مسیرهای API
│   ├── controllers/       # کنترل‌کننده‌ها
│   └── middleware/        # میان‌افزارها
├── web/                  # رابط وب
│   └── public/           # فایل‌های ایستا
├── database/             # پایگاه داده
├── _admin_secret/        # 🔐 محرمانه (فقط شما)
└── package.json
```

### 📡 API مسیرهای اصلی

```
GET  /api/status           - وضعیت سیستم
POST /api/ai/generate-text - تولید متن
POST /api/ai/generate-image- تولید تصویر
POST /api/ai/generate-video- تولید ویدئو
```
