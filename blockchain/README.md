# 🔗 بلاکچین ثریا

## ساختار

```
blockchain/
├── contracts/         # قراردادهای Solidity
├── sdk/              # SDK اتصال
├── nodes/            # گره‌های بلاکچین
└── scripts/          # اسکریپت‌های استقرار
```

## قراردادهای اصلی

### LOLOE.sol
- **توکن اصلی**: لؤلؤ‌سنجش
- **Supply**: بی‌نهایت (استخراج از مأموریت‌ها)
- **Decimals**: 18

### WorldLedger.sol
- **دفتر تراکنش‌های جهان**
- **ثبت موجودیت‌ها**
- **رویدادهای جهان**

### MissionSystem.sol
- **تعریف مأموریت‌ها**
- **توزیع پاداش‌های LOLOE**
- **تأیید تکمیل مأموریت**

## نحوهٔ استقرار

```bash
npm run blockchain:deploy
```
