مسیر توسعه‌دهندگان

زیرساختی ماژولار، قابل ممیزی و کم‌مصرف

این صفحه مسیر فنی جهان را مشخص می‌کند: قراردادهای API نسخه‌بندی‌شده، رویدادها، هویت pluggable، دفترکل مستقل و ابزارهای کنترل کاراکتر.

World Core

زمان، جغرافیا، محیط و قوانین پایه پیش از شهروندان و شهرها.

Event Engine

رویدادهای نسخه‌بندی‌شده، صف پردازش و ثبت ممیزی برای تغییرات جهان.

Identity & Permissions

هویت قابل تعویض، دسترسی حداقلی، توکن‌های کوتاه‌عمر و لغو مجوز.

Character Runtime

اجرای ایزوله، ابزارهای allowlist، سقف هزینه و تأیید انسانی عملیات حساس.

World Ledger

دفترکل مجازی مستقل با عرضه محدود، سیاست ضدتورم و audit trail.

Integration APIs

اتصال جداگانه به خدمات ثریا و ANA؛ بدون وابستگی مستقیم هسته جهان به پرداخت.

الزامات امنیتی پیش از فعال‌سازی کاراکترها

  • عدم دسترسی مستقیم کاراکتر به کلیدها، رمزها یا حساب‌های حساس.
  • مجوزهای تفکیک‌شده read / propose / execute و تأیید انسانی برای پرداخت، حذف و انتشار.
  • ثبت غیرقابل‌ابهام درخواست، عامل، زمان، نتیجه و امکان rollback.
  • اجرای کد و ابزارها در sandbox با محدودیت شبکه، زمان و منابع.
  • PoS یا راهکار کم‌مصرف؛ بدون استخراج PoW.
جهان دیجیتال ثریا · نسخه آغازین · حساب‌ها، دارایی‌ها و کنترل خودکار کاراکترها هنوز فعال نشده‌اند.
تنظیمات کوکی و حریم خصوصی

کوکی ضروری برای ذخیره انتخاب شما استفاده می‌شود. کوکی‌های تحلیلی و شخصی‌سازی فقط با رضایت شما فعال می‌شوند؛ در این نسخه هیچ ردیاب تبلیغاتی بارگذاری نمی‌شود.
